# خطة بناء موقع حرس الحدود

## نظرة عامة
موقع عسكري احترافي بواجهة عربية (RTL) مع Sidebar ثابت ديناميكي، صفحة رئيسية بسيطة فاخرة، وأقسام قابلة للإدارة بالكامل، ولوحة تحكم للمطور.

## التصميم
- ألوان: بني داكن، أخضر عسكري، رملي، أسود، لمسات ذهبية.
- خطوط عربية فاخرة (Cairo/Tajawal).
- مؤثرات: Framer Motion (fade/scale/reveal)، Floating Particles، Mouse follow، Hover glow، Ripple، Smooth scroll، Animated gradient background.
- RTL كامل + Responsive.

## الصفحات
1. `/` — الصفحة الرئيسية: عنوان كبير "مرحبًا بك في موقع حرس الحدود" + وصف + خلفية متحركة. لا شيء آخر.
2. `/s/$slug` — صفحة قسم ديناميكي (شبكة كروت للعناصر المنشورة).
3. `/s/$slug/$id` — صفحة تفاصيل عنصر (معرض صور + وصف كامل + مؤثرات).
4. `/auth` — تسجيل دخول المطور.
5. `/admin` — لوحة تحكم محمية:
   - إدارة **الأقسام**: إضافة/تعديل/حذف/إعادة ترتيب/إظهار في السايدبار.
   - إدارة **العناصر** داخل كل قسم: إضافة/تعديل/حذف/نشر.

## Sidebar (ديناميكي)
ثابت، يعرض: "الرئيسية" + كل الأقسام المفعّلة من قاعدة البيانات مرتبة حسب `sort_order`. عند إضافة/حذف قسم من لوحة التحكم يتحدّث السايدبار تلقائيًا. قابل للطي على الموبايل.

## قاعدة البيانات (Lovable Cloud)

جدول `sections`:
- id, slug (فريد), name (عربي), icon (اسم أيقونة lucide اختياري)
- sort_order (int), visible (bool), created_at

جدول `items`:
- id, section_id (FK → sections)
- title, short_description, full_description
- cover_image (url), gallery (text[] urls)
- published (bool), sort_order, created_at, updated_at

جدول `user_roles` + enum `app_role('admin')` + دالة `has_role()` أمنية (SECURITY DEFINER).

RLS:
- `sections`: SELECT للجميع حين `visible=true`؛ كل العمليات للأدمن.
- `items`: SELECT للجميع حين `published=true`؛ كل العمليات + قراءة المسودات للأدمن.
- `user_roles`: قراءة للمستخدم لنفسه؛ الكتابة للأدمن.

Storage bucket `media` عام لرفع صور الغلاف والمعرض.

بذور أولية: الأقسام الستة المطلوبة (إنجازات، أسلحة، سيارات، دورات، أماكن معتمدة) تُدرج في نفس الـ migration ليبدأ الموقع جاهزًا — ويمكن حذفها/تعديلها لاحقًا من لوحة التحكم.

## لوحة التحكم
- تسجيل دخول بالبريد/كلمة السر.
- تبويب "الأقسام": جدول + نموذج (الاسم، slug، الأيقونة، الترتيب، مرئي).
- تبويب "العناصر": فلترة حسب القسم، جدول، نموذج (عنوان، وصف مختصر، وصف كامل، رفع صورة غلاف، رفع عدة صور للمعرض، نشر).

## ملاحظة
أول مستخدم يسجّل يحتاج ترقية يدوية لأدمن عبر SQL — سأوضح الأمر بعد التسجيل.

## Stack
TanStack Start + Query + Router، Framer Motion، Tailwind، shadcn، Lovable Cloud.
